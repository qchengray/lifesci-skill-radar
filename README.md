# LifeSci Skill Radar · 生命科学技能雷达

追踪 AI 助手在生命科学研究中用得上的 **Agent Skills、插件、MCP 和结构可视化扩展**。重点是生物信息学，以及蛋白设计项目中的公开结构检索、注释和人工核对。这里是来源索引和 GitHub 观测站，不是安装器。

[每日榜与来源目录](catalog/README.md) · [周报与月报](reports/README.md) · [可复用的 JSON 来源清单](catalog/sources.json) · [采集规则](METHODOLOGY.md)

## 怎么读

- **找能用的东西**：先按研究任务选，再区分 Skill、Plugin、Marketplace、MCP 和编辑器扩展。每条有上游出处，区分原项目维护与社区实现。
- **看最近谁在增长**：每日榜同时列总星数、过去 1 天与 7 天净变化、以及可比时的排名升降。GitHub 星数按仓库统计，不是子插件的独立星数，也不是准确度或科研质量评分。
- **看趋势有没有证据**：每次观测留下带时间戳的 JSON；时间窗口有缺口时明确标注，不把缺失填成零，也不推算上线前的数据。
- **看变化**：北京时间每天约 08:17 刷新，周一汇总上一自然周，每月 1 日汇总上一个自然月。报告含日期端点、涨跌、当期新增与缺基线说明。

## 如何补充来源

欢迎提出来源建议。请给出上游仓库和一手证据，注明资源类型、适用研究任务、归属及限制。编目经人工筛选，不把关键词搜索结果自动加入公开榜。目录不包含运行命令或安装包；收录不表示已执行、审查源码、安全验证或推荐安装。使用外部插件前，核对其代码、许可证、数据去向和权限。

**English.** An independent index of agent skills, plugins, MCP servers, and structure-viewing extensions for bioinformatics and protein research. It records repository-level GitHub stars, day/week changes and comparable rank moves, and publishes calendar-week and calendar-month summaries in Beijing time. Counts are observed, not inferred. The catalog is not an installer or a quality endorsement.
